# Module Utilitaires

Ce module contient des classes utilitaires et des fonctions communes utilisées par l'ensemble de l'application de gestion de stock.

## Rôle et responsabilités

Le module `utilities` a pour mission de :

-   **Fournir des outils génériques** : Il contient des fonctions pour la manipulation de chaînes de caractères, de dates, de collections, etc.
-   **Éviter la duplication de code** : Il centralise les fonctionnalités réutilisables pour simplifier la maintenance.

## Technologies utilisées

-   **Java** : Langage de programmation principal.

## Comment utiliser ce module

Ce module est une bibliothèque qui est utilisée par d'autres modules. Il n'est pas destiné à être exécuté de manière autonome.

## Dépendances

Ce module ne dépend d'aucun autre module du projet.
